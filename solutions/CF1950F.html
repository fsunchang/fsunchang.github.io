前言

本题解思路来自 评论区。

题面翻译

一颗二叉树，由 a 个有两个子节点的节点，b 个只有一个子节点的节点以及 c 个叶节点构成（无解输出 −1）。

求最小深度（根节点深度为 0）。

共 T 组数据。

思路

我们可以先用“有两个子节点的节点”和“叶结点”构成完全二叉树，此时要求 c=a+1，否则无解。

此时深度为 ⌊log2⁡a⌋。

然后，用 2⌊log2⁡a⌋−c 个“只有一个子节点的节点”将其补为一颗任意叶结点到根都相同的二叉树。

若 b<2⌊log2⁡a⌋−c，则尽可能地填补。

令 b′←b−min{b,2⌊log2⁡a⌋−c}。

最后，用剩余的“只有一个子节点的节点”做为“叶结点”的父节点。

此时增加的深度为 ⌊b′+c−1c⌋。

易知此时深度最小。

时间复杂度：Θ(T)。

代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    int T;
    cin>>T;
    while(T--){
        int a,b,c;
        cin>>a>>b>>c;
        if(c!=a+1) cout<<-1<<endl;
        else{
            int log=a?(32-__builtin_clz(a)):0;
            b-=min(b,(1<<log)-c);
            cout<<log+(b+c-1)/c<<endl;
        }
    }
    return 0;
}
