## 前言

本题解参考 CF 官方题解。

奇妙思维题。

## 题面翻译

一个 $n \times m$ 的网格，初始为空。

$q$ 次询问：

1. 先将原为空的 $(r_i,c_i)$ 变为方块或圆圈。

2. 然后询问有多少种方案满足不存在三个相同类型的方格排成横线，竖线或对角线，对 $998244353$ 取模。

共有 $T$ 组数据。

## 思路

考虑一个不在边界上的 $2 \times 2$ 的网格：

发现只有 $2$ 个 **square** 和 $2$ 个 **circle** 时才满足条件。

反证法：

| **square** | **square** | **circle** |
| :--------: | :--------: | :--------: |
| **square** | **circle** |            |
| **circle** |            |            |

| **square** | **square** | **circle** |
| :--------: | :--------: | :--------: |
| **square** | **square** | **circle** |
|            |            | **circle** |

考虑一个 $3 \times 3$ 的网格：

发现包含以下 $4$ 种之一时才满足条件。

| **square** | **square** |
| :--------: | :--------: |
| **circle** | **circle** |

| **circle** | **circle** |
| :--------: | :--------: |
| **square** | **square** |

| **square** | **circle** |
| :--------: | :--------: |
| **square** | **circle** |

| **circle** | **square** |
| :--------: | :--------: |
| **circle** | **square** |

反证法：

| **circle** | **square** | **circle** |
| :--------: | :--------: | :--------: |
| **square** | **circle** | **square** |
| **circle** | **square** | **circle** |

容易发现以上 $4$ 种一旦出现，就可以确定所有格子的类型且有规律。

以第一种为例（$5 \times 5$）：

| **square** | **circle** | **circle** | **square** | **square** |
| :--------: | :--------: | :--------: | :--------: | :--------: |
| **circle** | **square** | **square** | **circle** | **circle** |
| **square** | **circle** | **circle** | **square** | **square** |
| **circle** | **square** | **square** | **circle** | **circle** |
| **square** | **circle** | **circle** | **square** | **square** |

考虑到这些网格可以移动，于是按照奇偶将一种拆为两种，共 $8$ 种。

于是每次操作时维护每一种是否与当前冲突，再统计即可。

答案最大为 $8$（所以那个对 $998244353$ 取模是用来混淆视听的）。

时间复杂度：$\Theta(\sum q)$。

## 代码

```cpp
#include<bits/stdc++.h> 
using namespace std;
bool a[8];
void solve(){
	int n,m,q,ans;
	scanf("%d%d%d",&n,&m,&q);
	for(int i=0;i<8;i++) a[i]=1;
	printf("8\n");
	while(q--){
		int x,y;
		scanf("%d%d",&x,&y);
		string st;
		cin>>st;
		bool c=(st=="circle"),s=(st=="square");
		if((x+(y+1)/2)%2) a[0]&=c,a[1]&=s;
		else a[0]&=s,a[1]&=c;
		if((x+y/2)%2) a[2]&=c,a[3]&=s;
		else a[2]&=s,a[3]&=c;
		if((y+(x+1)/2)%2) a[4]&=c,a[5]&=s;
		else a[4]&=s,a[5]&=c;
		if((y+x/2)%2) a[6]&=c,a[7]&=s;
		else a[6]&=s,a[7]&=c;
		ans=0;
		for(int i=0;i<8;i++) ans+=a[i];
		printf("%d\n",ans);
	}
}
int main(){
	int T;
	scanf("%d",&T);
	while(T--) solve();
	return 0;
}
```
